# Android runtime

`facerecognitionsdk.aar` — the same engine the native Android and iOS liveness apps run.

```text
example/android/libfacesdk/facerecognitionsdk.aar
```

Copy it from `Face-LivenessDetection-Android/libs/`, or download it from the
[engine release](https://github.com/Faceplugin-ltd/FaceRecognition-LivenessDetection-Android/releases/tag/latest).

Gradle fails with this path in the message when the file is absent.
